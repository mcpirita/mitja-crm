# Mitja CRM — личная CRM для outreach

Персональный инструмент для холодного outreach по Германии. Трекаем лидов, статусы (отправлено → ждём ответ → фоллоуап1 → фоллоуап2 → ответ/мёртв), даты касаний, что делать сегодня, шаблоны писем.

**Это не клиентский проект и не SaaS — это инструмент для самого Дмитрия.** В перспективе может стать частью продукта Mitja, но сначала — для себя, чтобы научиться на собственном кейсе.

---

## Протокол работы агента

В начале каждого нового чата:

1. Прочитай этот `CLAUDE.md` (делается автоматически).
2. Открой папку `plans/`, найди файл со статусом `активный` в шапке — это текущий план работы. Следуй ему.
3. Если активного плана нет — спроси у Дмитрия, с чего начинать.

При новой задаче:

- Если задача вписывается в активный план — работай в нём.
- Если это другая задача — поставь текущий план в `приостановлен`, создай новый план в `plans/`.

---

## Правила планов

1. **Один план = одна задача.**
2. **Имя файла:** `YYYY-MM-DD-название-задачи.md`.
3. **Статус в шапке** — `активный` / `приостановлен` / `завершён`.
4. План делится на фазы с чекбоксами `[ ]` / `[x]`.
5. Агент актуализирует план после каждой сессии.

## Принципы

- **Только для меня.** Не SaaS, не команда. Аутентификация — минимальная (один пользователь).
- **Ручной ввод на старте.** Никаких интеграций с Gmail/IMAP в первой итерации.
- **Простота.** Список + статусы + «что сегодня». Никаких графиков и аналитики до фидбэка.
- **Скорость.** Минимум кликов, чтобы занести лид и обновить статус.
