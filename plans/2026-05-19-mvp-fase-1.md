## Контекст (уточнён после Q&A 2026-05-19)

Оффер — **аренда коммерческой недвижимости в Германии**, **одно здание**, площади 100–250 м². 
Аудитория — 4 параллельных сегмента арендаторов: **гастро / услуги (фитнес/красота/медицина) / офисы-склады / развлечения**.
Адресат — общий `info@` / контакт на сайте (не конкретное лицо). Hook персонализации — текущая локация компании.
Объём — 5–10 касаний в неделю. Драфты писем Дмитрий принесёт в новом чате (DE + EN).
Главная боль — забывание / «волны» из-за основной работы.

Подробности — в memory `user-outreach-context`.

---

## Задача MVP-mini

Рабочий веб-инструмент к 2026-05-24, в который Дмитрий каждый день:
- заносит лидов (или импортирует из Google Sheet),
- видит «что делать сегодня» (новые + просроченные фоллоуапы),
- генерирует письмо по шаблону под сегмент → копирует в Outlook,
- обновляет статус лида одной кнопкой.

Что НЕ входит в Фазу 1 (см. отдельный план [Фаза 2](2026-05-19-mvp-fase-2-telegram-snooze.md)):
- Telegram-бот, утренний дайджест.
- Snooze / пауза лидов.
- Архив мёртвых.
- AI-генерация hook'а (Claude API). _Claude API всё равно подключаем для перевода — hook возможно подъедем бесплатно, но в скоуп Фазы 1 не включаем._
- Интеграция с календарём (отложено).
- Прямая отправка из CRM (SMTP / Outlook API).

**Изменение скоупа 2026-05-25:** добавлена Фаза 1.6 — перевод RU→DE через Claude API. Шаблоны сидим только на русском, в момент отправки переводим в немецкий в заданном стиле, копируем в Outlook.
