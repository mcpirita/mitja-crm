# План: Редизайн фронтенда CRM в визуальном языке «Штаба»

**Статус:** `завершён` (2026-09-02)

**Старт:** 2026-09-02
**Соседний план:** `2026-09-01-vosstanovlenie-crm-i-perebor-bazy.md` остаётся `активным` —
редизайн его не трогал, работа шла только по вёрстке.

**Задача.** CRM выглядела как дефолтный светлый Tailwind (zinc + белые карточки).
«Штаб» (`~/Websites/Project Shtab/index.html`) нравится больше — перенести его
визуальный язык на CRM, начиная с таблицы лидов.

---

## Что взяли из «Штаба»

- Палитра: графит `#080d12` / панель `#0f1720` / янтарь `#e8a13c`, текст `#dce6f0`.
- Шрифты: Unbounded (заголовки), Manrope (текст), JetBrains Mono (служебные подписи).
- Атмосфера: янтарное зарево + холодный подсвет, координатная сетка 64px, зерно.
- Детали: радиус 3px, засечки по углам панелей, моноширинные капсы с трекингом.

## Фазы

- [x] **Фаза 1. Токены.** `globals.css`: перевёрнутая шкала `zinc` (zinc-50 — самый
      тёмный фон, zinc-900 — основной текст) + `--color-white` = панель. За счёт
      этого 5800 строк старой разметки переехали в тёмную тему без правок.
      Семантические цвета (rose/red/amber/emerald/blue) переопределены: шаги 50–300
      стали полупрозрачными подложками, 600–900 — светящимся текстом. Шаги 400/500
      не трогали — на них держатся образцы цвета сегментов.
- [x] **Фаза 2. Каркас.** `layout.tsx` (шрифты через next/font, зерно, ширина 1240px),
      `TopNav` (липкая шапка, градиентный логотип, моно-вкладки), `PageHeader`
      (`/// Заголовок` + линия), `EmptyState`.
- [x] **Фаза 3. Таблица лидов.** `LeadsListClient` — пульт фильтров с моно-подписями
      и сводкой (всего / в работе / горячие); `.ops` — реестр: нумерация строк,
      сигнальная планка приоритета слева, точки сегментов вместо пастельных плашек,
      чипы статусов по тонам, индикатор приоритета из трёх делений, дата + «сколько
      назад», стрелка перехода по наведению, ступенчатое появление строк.
- [x] **Фаза 4. «Сегодня».** Карточки с сигнальной планкой срочности, заголовки
      секций (подпись · линия · счётчик), таблица «Все активные» на `.ops`.
- [x] **Фаза 5. Остальные экраны.** Карточки → `.panel` с засечками, кнопки → `.btn` /
      `.btn-primary`, заголовки внутри панелей → моно-капсы, таблицы сегментов /
      помещений / шаблонов → `.ops`.

- [x] **Фаза 6. Иконка.** Тот же кафель, что у «Штаба» (сетка, зарево, уголки
      прицела), знак — геометрическая M с точкой из логотипа. Набор: `icon.svg`,
      192/512, 512-maskable, apple-touch-icon 180, `favicon.ico` с 16/32/48
      (для мелких размеров отдельный вариант: знак крупнее, сетка убрана).
      Манифест и иконки выведены из-под авторизации — браузер тянет их
      отдельным запросом без Basic-заголовка и на 401 молча остаётся без иконки.
      Исходники вариантов SVG — в `design/icons/`.
- [x] **Фаза 7. Вход вместо Basic Auth.** Chrome не показывает системный диалог
      Basic Auth в установленном как приложение окне — вводить креды негде.
      Сделали форму `/login` и подписанную куку `mitja_session` (HMAC от самих
      кредов, 90 дней): на Vercel новых переменных не нужно, смена пароля
      разлогинивает. Заголовок `Authorization: Basic` продолжаем принимать для
      curl и скриптов; `/api/*` под 401 отдаёт JSON, а не редирект на форму.

## Проверено

- `npm run build` — зелёный, шрифты next/font тянутся при сборке.
- `npx tsc --noEmit` — без ошибок.
- Скриншоты headless Chrome: `/leads`, `/today`, `/leads/1`, `/segments`, `/import`,
  `/login` на 1400px и на 600px (мобильная раскладка: шапка и фильтры переносятся,
  таблица скроллится внутри панели).
- Вход прогнан curl'ом с включёнными кредами: `/today` без куки → 307 на `/login`,
  неверный пароль → 401, верный → кука и 200, `/api/leads` без куки → 401 JSON,
  `Authorization: Basic` → 200, иконки и манифест → 200, выход → 303 на `/login`.

## Не сделано намеренно

- Светлой темы нет: инструмент личный, тёмная — единственная.
